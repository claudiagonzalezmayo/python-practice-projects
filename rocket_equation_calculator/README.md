# Rocket Equation Calculator

A Python implementation of the Tsiolkovsky rocket equation.

The program calculates the change in velocity of a rocket from its initial mass, final mass, and exhaust velocity.

## Inputs

* Initial mass
* Final mass
* Exhaust velocity

## Output

* Δv

## Concepts practiced

* Functions
* Input validation
* Mathematical calculations
* Scientific notation
